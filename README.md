# Лабораторная работа № 2

Вариант 15. Родительский процесс передаёт строки дочернему через канал. Дочерний записывает в файл строки, начинающиеся с заглавной латинской буквы `A`–`Z`, а сообщения об остальных строках возвращает родителю через второй канал

## Сборка и запуск

```sh
cmake -S src -B build
cmake --build build
cd build
./parent
```

Первой строкой введите имя выходного файла, затем строки для проверки. Завершите ввод сочетанием `Ctrl+D`. Программа создаёт или перезаписывает указанный файл. Исходники находятся в `src/`, отчёт — в `report/`
